# 拾词 · 英语复习本 (Shici Wordbook)

支持 **iPhone 主屏幕全屏 Web App** 与 **GitHub Gist 双端自动云同步** 的个人英语复习本。

## 功能特点
- **极速加载**：页面体积从 48MB 降至 150KB，568 条真人美式录音拆分为按需加载的独立音频并支持离线缓存。
- **iPhone 原生级体验**：支持 Safari「添加到主屏幕」全屏运行，适配灵动岛/安全区域及 iOS 系统英式/美式语音朗读。
- **双端自动云同步**：基于 GitHub 私密 Gist 免费同步，电脑与 iPhone 新增词汇、修改笔记、随机测验进度自动双向合并。
