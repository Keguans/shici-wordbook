☁ 手机与电脑云端同步

通过你自己的 GitHub 账号（私密 Gist）免费同步词库与练习进度，无需购买服务器。任何一边新增、编辑词汇或完成测验，另一边打开即可自动同步。

首次设置只需 2 步：
  1. 点击打开 GitHub Token 生成页（已自动勾选 gist 权限），滚到底部点击绿色 Generate token。
  2. 把生成的 ghp_... 密钥粘贴到下方，点击「连接并立即同步」。电脑端连上后可一键复制「手机配对码」发给 iPhone！

📱 iPhone 桌面 App 小贴士：
在 iPhone 的 Safari 浏览器打开本网页，点击底部中间的 「分享」图标 →「添加到主屏幕」，即可像独立 App 一样在手机桌面全屏使用！
